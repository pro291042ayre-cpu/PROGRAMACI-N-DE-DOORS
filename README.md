# PROGRAMACI-N-DE-DOORS
DOORS es un juego de terror desarrollado en Roblox por LSPLASH.

# Cómo abrir el proyecto en Roblox Studio

Para que otros puedan usar tu copia del juego en Roblox Studio, sigue estos pasos:

---

## 📥 Descargar el archivo
1. Ve al repositorio en GitHub.
2. Haz clic en el botón **Code → Download ZIP**.
3. Extrae el archivo `.zip` en tu computadora.
4. Dentro encontrarás el archivo del juego en formato `.rbxl` o `.rbxlx`.

---

## 🚀 Abrir en Roblox Studio
1. Abre **Roblox Studio** en tu PC.
2. Ve a la barra superior y selecciona **File → Open...**.
3. Busca el archivo `.rbxl` o `.rbxlx` que descargaste.
4. Haz clic en **Open** y el proyecto se cargará en Roblox Studio.
